**Taller de Programación**    
**Ejercicio: Clon visual de la página de Starlink**

**Objetivo**    
Reproducir, con la mayor fidelidad posible, la página oficial de Starlink: [https://www.starlink.com/](https://www.starlink.com/)

No se pide el backend real (compras, login, disponibilidad por dirección). Se pide un **clon visual y de interacción** de la interfaz: layout, tipografía, colores, espaciado, secciones, hover, menús y comportamiento responsive.

**Alcance mínimo (obligatorio)**    
Clonar la **home** completa, de arriba abajo, incluyendo:

1. Header fijo o sticky    
      - Logo STARLINK    
      - Navegación: Residential, Roam, Resources (con dropdown), Service Plans    
      - Acciones: teléfono, Personal / Business, selector de idioma/región e ícono de cuenta    
2. Hero principal    
      - Fondo oscuro    
      - Título grande (“Fast, affordable internet” o el copy vigente al momento de entregar)    
      - Precio destacado (servicio desde $55/mo)    
      - Botones Get Started y View Pricing    
3. Sección de planes    
      - Residential 100 Mbps, 200 Mbps, Max    
      - Planes Roam    
      - Cards con bullets, precio y CTA    
4. Bloques de contenido posteriores    
      - Internet en casa / en movimiento    
      - Speeds (hasta 400+ Mbps)    
      - Plug it in / Point at sky    
      - Disponibilidad global    
      - Engineered by SpaceX / trial de 30 días si aparece en la home    
5. Footer completo    
      - Columnas de links, legal, redes y copyright

**Alcance extra (opcional, suma puntos)**    
- Página Residential o Roam con el mismo estilo    
- Modal o panel de “Get Started” (formulario simulado)    
- Dropdowns y menú mobile    
- Transiciones suaves al hacer scroll    
- Dark UI consistente en toda la experiencia

**Requisitos técnicos**    
- HTML semántico + CSS TailwindCSS 4.2 (y JS solo si hace falta para menú, tabs o dropdowns)    
- Responsive: desktop, tablet y móvil    
- No vale un simple screenshot ni un iframe de la web real    
- Tipografías, tamaños, pesos, márgenes y contraste lo más cercanos posible    
- Imágenes: pueden usar las oficiales **solo para práctica local**. Si publican el proyecto, reemplazar por placeholders o assets propios y aclararlo en el README    
- El sitio debe verse y sentirse como Starlink, no “inspirado en”

**Entrega**    
- Repositorio (Local) con README    
- En el README: link de preview    
- Instrucciones para correrlo en local    
- Nota breve: qué lograron clonar bien y qué no

**Criterios de evaluación**    
- Fidelidad visual (40%)    
- Estructura y calidad del código (25%)    
- Responsive y usabilidad (20%)    
- Detalles de interacción (menú, hover, botones) (10%)    
- Presentación y README (5%)

 
**Modalidad:** individual 

**Aclaración**    
Este ejercicio es académico. No se está creando un producto comercial ni se debe hacer pasar el clon por el sitio oficial.
